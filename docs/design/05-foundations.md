## 2. الخطوط `[مقترح]`

### الخيار الموصى به — A: IBM Plex Sans Arabic

| البند | القيمة |
| --- | --- |
| خط الواجهة والمحتوى | `IBM Plex Sans Arabic` |
| المرافق اللاتيني | `IBM Plex Sans` (نفس العائلة، نفس البُنية) |
| المرافق للأرقام/الكود (IP، Port، API Key المُقنَّع) | `IBM Plex Mono` |
| الأوزان المستخدمة | 400 Regular / 500 Medium / 600 SemiBold / 700 Bold |
| الترخيص | SIL Open Font License 1.1 — يسمح بالتضمين المحلي |

**سبب الترشيح، مربوطاً بالقيود:**
- القيد 2: العائلة الوحيدة بين المرشحات التي لها **مرافق لاتيني ومونوسبيس من نفس التصميم**، فتظهر "API Key" و"Model" و"gpt-4o" متجانسة مع النص العربي دون قفزة بصرية.
- القيد 8: تصميمها مخصص أساساً لواجهات كثيفة، فتبقى مقروءة في جداول T10/T11/T17 عند 13–14px وعلى 1024×768.
- القيد 11: OFL + ملفات static/variable تُضمَّن مع حزمة Electron.
- القيد 10: أشكال حروف مفتوحة وارتفاع س كبير، مناسبة لنص الدرس الطويل.

### البديلان في النموذج للمقارنة

| الخيار | الخط | ملاحظة مربوطة بالقيود |
| --- | --- | --- |
| B | `Cairo` (واجهة) + `Noto Sans Arabic` (قراءة) | مألوف جداً عربياً وودود؛ لكن يتطلب **عائلتين** ومرافقه اللاتيني ليس من نفس التصميم (يضعف القيد 2) |
| C | `Almarai` (واجهة) + `Noto Sans Arabic` (قراءة) | هندسي ونظيف؛ أربعة أوزان فقط ولا مرافق لاتيني/مونو مطابق (يضعف القيدين 2 و12) |

القرار يُتخذ على **النموذج البصري**، لا على هذا الجدول.

### مقياس النص — واجهة الطالب (Mobile-first، 360px)

الجذر 16px (القيد 9).

| Token | الحجم | ارتفاع السطر | الوزن | الاستخدام |
| --- | --- | --- | --- | --- |
| `s-h1` | 24px | 1.35 | 700 | عنوان S01/S04 |
| `s-h2` | 20px | 1.4 | 600 | عنوان درس في S05 |
| `s-body` | 16px | 1.75 | 400 | النص الافتراضي |
| `s-label` | 15px | 1.5 | 500 | Labels الحقول |
| `s-caption` | 13px | 1.6 | 400 | تاريخ النشر، timestamp |

`s-reading` بارتفاع سطر 1.85 لأن النص العربي بحركات وهمزات يحتاج فراغاً رأسياً أكبر من اللاتيني.

### قواعد نصية إضافية

- `letter-spacing: 0` للعربية دائماً — التتبّع يفكك الاتصال بين الحروف.
- **الأرقام: عربية `٠–٩`** في كل ما يراه المستخدم — الأعداد، الأوقات، التواريخ، العدّادات، خطوات الترقيم. `[معتمد]`
- **تبقى لاتينية `0–9`** في القيم التقنية وحدها، وهي القيم التي تُنسخ أو تُقارن حرفياً: رابط الدخول، IP/Port، أسماء النماذج، المفتاح المُقنَّع، أرقام إصدار التطبيق. هذه القيم تعيش أصلاً داخل جزيرة `dir="ltr"` وبخط `--font-mono`، فالفصل بينها وبين نص الواجهة قائم بالفعل.
- `font-variant-numeric: tabular-nums` في الجداول والعدّادات (T09 live stats، T15 submissions count) لمنع اهتزاز الأرقام عند التحديث.
  ⚠ **يُتحقق منه في أول بناء**: هل يغطي `tnum` في IBM Plex Sans Arabic الأرقام العربية `٠–٩` كما يغطي اللاتينية؟ إن لم يغطِّها، البديل هو تثبيت عرض حاوية العدّاد بـ `min-width` بدل الاعتماد على الخاصية. لم يُتحقق من هذا بصرياً بعد.
- لا يُستخدم `text-transform: uppercase` — بلا معنى للعربية ويضر بالمصطلح اللاتيني المختلط.
- الحد الأقصى لعرض سطر القراءة في S06: `72ch`.

## 3. الألوان `[مقترح]`

كل نسبة أدناه **محسوبة** بمعادلة WCAG 2.1 ومثبتة في العمود الأخير، لا مقدّرة.

### المحاور المحيّدة (Neutrals)

| Token | Hex | تباين | الاستخدام |
| --- | --- | --- | --- |
| `--canvas` | `#F8FAFC` | — | خلفية الصفحة |
| `--surface` | `#FFFFFF` | — | Cards، Sidebar، Drawer، Dialog |
| `--surface-2` | `#F1F5F9` | — | صفوف الجدول البديلة، الحالة المعطّلة |

| الحالة | نص المستخدم | السطح | الحدود | النص | تباين النص | الأيقونة |

| **Pending / بانتظار الموافقة** | "طلب بانتظار الموافقة" | `#FFFBEB` | `#FDE68A` | `#92400E` | **6.84** | ⏳ clock |

### أزرار الحالة الصلبة

| Token | Hex | تباين مع أبيض | الاستخدام |
| --- | --- | --- | --- |
| `--success` | `#15803D` | **5.02** | تأكيد "قبول" |
| `--warning` | `#B45309` | **5.02** | تنبيه غير مانع |
| `--danger` | `#B91C1C` | **6.47** | **"إنهاء دخول الطلاب"** (القيد 5)، "رفض"، حذف فصل/طالب، Restore backup |

## 4. باقي الـ Tokens `[مقترح]`

مطلوبة نصاً في Deliverables: *"Design tokens: type scale، spacing، radii، shadows، semantic colors، states"*.

### Spacing — أساس 4px

`--sp-1: 4px` · `--sp-2: 8px` · `--sp-3: 12px` · `--sp-4: 16px` · `--sp-5: 20px` · `--sp-6: 24px` · `--sp-8: 32px` · `--sp-10: 40px` · `--sp-12: 48px` · `--sp-16: 64px`

### Radii

`--r-sm: 6px` (badge, input) · `--r-md: 10px` (button, card داخلي) · `--r-lg: 14px` (card, dialog) · `--r-xl: 20px` (لوحة QR في T09) · `--r-full: 999px` (avatar, chip)

### Shadows — خفيفة، فالمنتج Desktop لا Web ترويجي

| Token | القيمة | الاستخدام |
| --- | --- | --- |
| `--sh-1` | `0 1px 2px rgba(15,23,42,.06)` | Card ساكن |
| `--sh-2` | `0 4px 12px rgba(15,23,42,.08)` | Card مرفوع، Dropdown |
| `--sh-3` | `0 12px 32px rgba(15,23,42,.14)` | Drawer (T14)، Dialog، Toast |

### المقاسات والحالات

| Token | القيمة | المصدر/السبب |
| --- | --- | --- |
| `--h-control` | 40px (Teacher) / **44px (Student)** | القيد 9: touch targets |
| `--h-control-sm` | 32px | أزرار داخل صفوف الجداول (T10/T11/T17) |
| `--w-sidebar` | 256px، مطوية 64px | القيد: Sidebar قابلة للطي عند عرض ضيق |
| `--w-content-max` | 1120px | داخل baseline 1280 |
| `--focus-ring` | `2px solid var(--focus)` + offset 2px | القيد 7 |
| `--disabled` | نص `#94A3B8` على `#F1F5F9` | ⚠ تباين 2.34 — **لا يُستخدم لنص يجب قراءته**؛ العنصر المعطّل يُرفق دائماً بنص توضيحي بلون `--text-muted` يشرح سبب التعطيل (القيدان 3 و4) |
| `--motion-fast` / `--motion-base` | 120ms / 200ms، `ease-out` | حركة قصيرة؛ يجب احترام `prefers-reduced-motion` |

### الاتجاه — RTL

- كل خصائص التخطيط منطقية: `margin-inline-start`، `padding-inline-end`، `inset-inline-start`.
- `dir="rtl"` على `<html>`، و`dir="ltr"` على حاويات القيم اللاتينية فقط (رابط الدخول، IP/Port، مفتاح مُقنَّع).
- أيقونات الاتجاه (back/next، chevrons، سهم الـ drawer) **تُعكس** أفقياً (القيد: RTL icons directional).
- أيقونات غير اتجاهية (check، clock، alert، sparkles، trash) **لا تُعكس**.

## 5. تعريف CSS جاهز للمراجعة

```css
:root {
  /* Fonts — bundled locally, no CDN (constraint 11) */
  --font-ui: "IBM Plex Sans Arabic", "IBM Plex Sans", system-ui, sans-serif;
  --font-mono: "IBM Plex Mono", ui-monospace, monospace;

  /* Neutrals */
  --canvas: #F8FAFC;  --surface: #FFFFFF;  --surface-2: #F1F5F9;
  --border: #E2E8F0;  --border-input: #7C8CA0;
  --text: #0F172A;    --text-2: #334155;   --text-muted: #64748B;

  /* Primary */
  --primary: #0F766E;  --primary-hover: #115E59;
  --primary-soft: #F0FDFA;  --primary-on-soft: #115E59;
  --focus: #0F766E;

  /* Status surfaces (always paired with an icon + text) */
  --ok-bg: #ECFDF5;      --ok-border: #A7F3D0;   --ok-text: #166534;
  --pending-bg: #FFFBEB; --pending-border: #FDE68A; --pending-text: #92400E;
  --error-bg: #FEF2F2;   --error-border: #FECACA; --error-text: #991B1B;
  --draft-bg: #F1F5F9;   --draft-border: #CBD5E1; --draft-text: #475569;
  --ai-bg: #F5F3FF;      --ai-border: #DDD6FE;   --ai-text: #5B21B6;

  /* Solid status */
  --success: #15803D;  --warning: #B45309;  --danger: #B91C1C;  --ai: #6D28D9;

  /* Spacing / radii / shadows */
  --sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px; --sp-5:20px;
  --sp-6:24px; --sp-8:32px; --sp-10:40px; --sp-12:48px; --sp-16:64px;
  --r-sm:6px; --r-md:10px; --r-lg:14px; --r-xl:20px; --r-full:999px;
  --sh-1: 0 1px 2px rgba(15,23,42,.06);
  --sh-2: 0 4px 12px rgba(15,23,42,.08);
  --sh-3: 0 12px 32px rgba(15,23,42,.14);

  /* Sizing */
  --h-control: 40px; --h-control-sm: 32px;
  --w-sidebar: 256px; --w-content-max: 1120px;
  --motion-fast: 120ms; --motion-base: 200ms;
}

/* Student web overrides — mobile-first, larger touch targets */
:root[data-app="student"] { --h-control: 44px; }
```
