# Docs landing identity

The landing page introduces CubeCroom as a calm, local classroom workspace.

- Keep the existing cube symbol and CubeCroom name recognizable across header and footer.
- Use deep teal for emphasis, warm neutral surfaces, and restrained sand accents. Avoid an unrelated black section interrupting the photographic palette.
- Emirati character comes from the people, clothing, photographic light, and a restrained geometric rhythm inspired by Sadu. Decorative SVGs stay hidden from assistive technology.
- Preserve the white hand-drawn annotations in the editorial photos. Avoid adding decorative marks everywhere.
- Product screenshots must come from the real documentation capture assets. Prefer populated screens, explain the teacher/student roles, and allow opening the original for legibility.
- Primary action leads to the getting-started documentation; secondary action previews the product.
- Keep the landing server-rendered, with Tailwind utilities and shared shadcn primitives. Avoid animation dependencies and respect reduced-motion preferences.

Review on desktop and narrow screens after changes. Platform compatibility remains a project requirement; browser checks on macOS do not establish native Windows or Linux validation.
