---

يستطيع CubeCroom أن يعطي تطبيقات الذكاء الاصطناعي المثبّتة على جهاز المعلم نفسه، مثل Claude Desktop وCursor وVS Code، قراءةً لدروسك وأنشطتك وتجارب التعلم ونتائج فصولك عبر بروتوكول [MCP](https://modelcontextprotocol.io). القراءة مطفأة حتى تفتحها بنفسك، ولا يستطيع أي تطبيق أن يغيّر شيئاً في بياناتك.

## ما يُعطى وما لا يُعطى

| يُعطى | لا يُعطى |
| --- | --- |
| أسماء الفصول وأعداد طلابها ودروسها وأنشطتها | أسماء الطلاب ومعرّفاتهم |
| نص الدروس، ومنها المسودات | الخيار الصحيح والإجابة المتوقعة في الأنشطة |
| أسئلة الأنشطة وخياراتها كما يراها الطالب | إجابات تجارب التعلم وشروحها ومعايير تصحيحها |
| مجاميع النتائج: عدد التسليمات والمراجعات، وتوزيع الدرجات، وعدد من اختار كل خيار | إجابة كل طالب ودرجته وتعليقك عليها |
| مجاميع التقدم لكل هدف تعلم | أي إنشاء أو تعديل أو نشر أو تصحيح |

في فصلٍ صغير جداً قد يدلّ المجموع على طالبٍ بعينه؛ خذ ذلك في الحسبان قبل التفعيل.

## إلى أين تذهب البيانات؟

الاتصال بين CubeCroom والتطبيق يبقى داخل الجهاز، لكن البيانات لا تبقى بالضرورة. ما يقرؤه التطبيق يصل إلى نموذج الذكاء الاصطناعي الذي يستخدمه ذلك التطبيق، وفق شروط مزوّده وإعدادات حسابك فيه، لا إلى [المزوّد المختار في CubeCroom](/docs/ai/ai-privacy). فـClaude Desktop مثلاً يرسل ما يقرؤه إلى Anthropic. راجع سياسة مدرستك قبل التفعيل.

## التفعيل

1. افتح «الذكاء الاصطناعي»، ثم شغّل «السماح بالقراءة عبر MCP» في بطاقة «تطبيقات الذكاء الاصطناعي على هذا الجهاز».
2. انسخ الإعداد الذي يظهر تحت المفتاح. فيه مسار CubeCroom على جهازك، فلا تنسخه من جهاز آخر.
3. أضفه إلى إعداد خوادم MCP في تطبيقك، ثم أعد تشغيل ذلك التطبيق.

| التطبيق | أين يُضاف الإعداد |
| --- | --- |
| Claude Desktop | الملف `claude_desktop_config.json` تحت `mcpServers`: على macOS في `~/Library/Application Support/Claude/`، وعلى Windows في `%APPDATA%\Claude\`. |
| Cursor | الملف `~/.cursor/mcp.json` لكل المشاريع، أو `.cursor/mcp.json` داخل مشروع، تحت `mcpServers`. |
| VS Code | الملف `.vscode/mcp.json` أو إعداد المستخدم من الأمر «MCP: Open User Configuration»، تحت `servers`، مع إضافة `"type": "stdio"` إلى الإعداد نفسه. |

وأي تطبيق آخر يشغّل خوادم MCP المحلية بطريقة stdio يحتاج القيم نفسها: الأمر، والوسائط، والمتغير `ELECTRON_RUN_AS_NODE`.

## إذا لم يتصل التطبيق

- **رسالة «CubeCroom is not open»**: افتح CubeCroom وتأكد أن المفتاح ما زال مفتوحاً. القراءة متاحة ما دام CubeCroom مفتوحاً فقط.
- **رسالة «بيانات CubeCroom غير مفتوحة بعد»**: أكمل فتح بياناتك في CubeCroom ثم أعد المحاولة.
- **على macOS**: انقل CubeCroom إلى مجلد «التطبيقات» قبل التفعيل. التطبيق الذي يُشغَّل من مكان تنزيله يعمل من مسار مؤقت يتغيّر، وتظهر رسالة بذلك تحت المفتاح.
- **على Linux**: إذا نقلت ملف AppImage أو استبدلته بملف باسم مختلف، انسخ الإعداد من جديد لأن المسار تغيّر.

لإيقاف القراءة أطفئ المفتاح، فتنقطع التطبيقات المتصلة فوراً. الإعداد لهذا الجهاز وحده، ولا يدخل النسخ الاحتياطية.
