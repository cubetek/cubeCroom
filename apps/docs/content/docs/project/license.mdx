## من داخل التطبيق والحصة

في إعدادات المعلم، أو صفحة الطالب، اضغط **«حول البرنامج والرخصة»**. تعرض النافذة رقم الإصدار والرخصة واسم صاحب الحقوق، وتتيح:

- فتح **«نص الرخصة الكامل»** لقراءته داخل النافذة.
- فتح **«الشيفرة المصدرية»**، واختيار **«تنزيل مصدر هذه النسخة»** عندما يتوفر الرابط في الحزمة.
- قراءة **«تراخيص المكتبات وإشعاراتها»** التي شُحنت مع التطبيق.

تُقرأ الرخصة والإشعارات من التطبيق أو من بوابة المعلم نفسها. فتح مستودع الشيفرة أو تنزيل مصدره من GitHub يحتاج إلى اتصال بالإنترنت.
