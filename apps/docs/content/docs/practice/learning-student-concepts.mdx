## ماذا تفعل هنا

- اقرأ المفاهيم ثم اختر المقابل لكل مفهوم.
- راقب الروابط التي تظهر في الخريطة أثناء الاختيار.
- أكمل العلاقات واحفظ المحاولة للتحقق منها.

<Callout title="انتبه">
الخريطة الحالية مطابقة بين مفاهيم وعلاقات يحددها المعلم، وليست مساحة رسم حرة.
</Callout>
