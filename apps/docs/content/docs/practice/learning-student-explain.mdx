## ماذا تفعل هنا

- اقرأ المعايير قبل كتابة تفسيرك.
- اكتب الفكرة والسبب ومثالاً مناسباً، ثم احفظ المحاولة.
- بعد مراجعة المعلم، افتح «محاولاتي وملاحظات المعلم» و«عرض أحدث الملاحظات».

<Callout title="انتبه">
لا يمنح البرنامج درجة تلقائية للتفسير. المعلم يحدد مدى استيفاء المعايير ويكتب ملاحظته.
</Callout>
