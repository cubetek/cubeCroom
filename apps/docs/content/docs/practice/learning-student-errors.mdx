## ماذا تفعل هنا

- حدد الادعاء الخاطئ في الموقف.
- اكتب التصحيح والدليل أو السبب، وأكمل المعايير التي يعرضها المعلم.
- احفظ الإجابة، ثم راجع ملاحظات المعلم لاحقاً.

<Callout title="انتبه">
في المثال المصور، سؤال محقق الأخطاء تفسيري؛ صحة عبارة قصيرة لا تعني استيفاء جميع المعايير.
</Callout>
