## ماذا تفعل هنا

- حدد هدف تعلم يمكن التحقق منه، ثم اكتب السؤال أو الموقف.
- للاسترجاع، اكتب كل صياغة مقبولة في سطر مستقل. للاختيار حدد الإجابة الصحيحة؛ وللترتيب والمطابقة حدد مفتاح كل خطوة أو علاقة.
- أضف التفسير الذي يظهر بعد المحاولة، وتلميحاً أو مثالاً مساعداً عند الحاجة.
- للسؤال التفسيري، اكتب الإجابة المتوقعة ومعايير التقييم. اضغط «أضف سؤالاً» لتوسيع التجربة ثم «حفظ التجربة».

<Callout title="انتبه">
مفتاح المعلم خاص به. الاسترجاع يقارن الإجابة بالصياغات المقبولة؛ استخدم سؤالاً تفسيرياً إذا كانت الإجابة تحتمل تعبيرات كثيرة.
</Callout>
