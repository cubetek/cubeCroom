## ماذا تفعل هنا

- بعد الحفظ تظهر رسالة وتفسير وموعد مراجعة عند توفره.
- إذا احتاجت إجابتك مراجعة، قارنها بالتفسير ثم تابع؛ لا يمكنك تغيير المحاولة المحفوظة.
- اضغط «إنهاء الجولة» عند آخر سؤال. تبقى المحاولة لدى المعلم.

<Callout title="انتبه">
الإجابات التفسيرية تنتظر مراجعة المعلم. الإجابة الصحيحة مرة واحدة لا تثبت الإتقان طويل المدى.
</Callout>
