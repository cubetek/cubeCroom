## ماذا تفعل هنا

- توضح كل بطاقة الطريقة والعنوان وعدد الأسئلة وحالة النشر والنسخة.
- افتح البطاقة لتعديلها أو معاينتها أو مراجعة نتائجها.
- استخدم «إيقاف النشر» عندما تريد منع بدء محاولات جديدة؛ ويمكنك إتاحة التجربة مجدداً.

<Callout title="انتبه">
تحفظ المحاولة نسخة الأسئلة التي بدأت بها. تعديل التجربة لا يعيد كتابة الإجابات السابقة. حفظ تعديل لتجربة منشورة يغيّر المحتوى الذي تبدأ به المحاولات الجديدة.
</Callout>
