## ماذا تفعل هنا

- اذكر عنوان المسودة وما تريد إصلاحه، مثل: «أصلح المسودة لتطابق نص الدرس ثم انشرها».
- يقرأ الفريق المسودة ويحتفظ بهويتها ويعالج محتواها، ثم يفحص النسخة الجديدة وينشرها وفق تفويض الفصل.
- تظهر النتيجة والإصدار المنشور في السجل. يمكنك توسيع التفاصيل لمعرفة ما عُدّل.

<Callout title="انتبه">
الإصلاح الآلي يخص المسودات غير المنشورة داخل الدرس المختار. عند تغيير النسخة أثناء العمل أو نقص معلومة لا يحلها المصدر، يذكر الفريق السبب.
</Callout>
