## ماذا تفعل هنا

- افتح «فريق المساعدين» واختر الفصل نفسه بعد إعادة تشغيل التطبيق.
- ابحث عن «توقفت ويمكن استئنافها»، واقرأ سبب التوقف والأعمال التي سبق حفظها.
- اضغط «استئناف» ثم تابع الحالة حتى انتهاء التنفيذ. تبقى الأعمال السابقة مرتبطة بالمهمة.

<Callout title="انتبه">
عالج سبب التعثر قبل الاستئناف. لا تحتاج المهمة المنقطعة إلى طلب جديد؛ المهام الملغاة لها سلوك مختلف.
</Callout>
