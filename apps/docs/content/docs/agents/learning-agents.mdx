## ماذا تفعل هنا

- بعد إعداد اتصال الذكاء الاصطناعي مرة واحدة، ابدأ من [الطلب المبسط](/docs/agents/learning-agent-simple).
- إذا أردت تخصيص مختص بعينه، افتح «تخصيص الفريق (اختياري)» ثم اختره.
- يمكنك تعديل شخصيته وذاكرته أو تكليفه مباشرة؛ لا يلزم ذلك لبدء العمل مع المنسق.

<Callout title="انتبه">
جودة النتيجة تعتمد على النموذج ومادة الدرس. يعالج الفريق ما يستطيع، ويذكر المعلومة الناقصة أو سبب التعثر عند الحاجة.
</Callout>

راجع [دليل فريق المساعدين](/docs/agents/learning-agent-guide).
