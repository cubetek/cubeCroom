title: "دع الفريق يجهّز العمل من طلب واحد"
description: "اطلب النتيجة؛ يتولى الفريق اختيار الأسلوب وإعداد التجربة وفحصها."
---


افتح [الطلب المبسط](/docs/agents/learning-agent-simple) واضغط «جهّز تجربة للدرس» ثم «ابدأ المهمة». يمكنك كتابة قيد قصير مثل: «أريد مراجعة ممتعة في خمس دقائق». يعرف المنسق الفصل والدرس المختارين ويستعين بالمختصين بنفسه؛ لا تحتاج إلى توزيع المهمة بينهم.

بعد إعداد مصدر الدرس واتصال الذكاء الاصطناعي، تبقى هذه الإعدادات محفوظة. [تفويض النشر](/docs/agents/learning-agent-publish) محفوظ أيضاً لكل فصل: يتيح للفريق نشر التجربة بعد الفحص؛ وعند إيقافه يحفظ مسودة.

| المختص | ما يتولاه داخل الفريق |
| --- | --- |
| منسق المعلم | اختيار الأسلوب وتنسيق النتيجة المطلوبة |
| مصمم الدرس | صياغة الأهداف والأمثلة من النص |
| مختص التقييم | إعداد الأسئلة ومفاتيحها ومعاييرها |
| مصمم تجارب اللعب | تصميم التحديات والتفرعات |
| مختص المراجعة | اقتراح استرجاع ومراجعات مناسبة |
| محلل التعلم | قراءة المحاولات والدرجات الجزئية وما لم يصحح |
| مراجع الجودة | التحقق من الدقة واتساق المحتوى مع المصدر |

## خيارات إضافية عندما تحتاجها

الشخصيات جاهزة للعمل. من «تخصيص الفريق (اختياري)» يمكنك تعديل [الشخصية](/docs/agents/learning-agent-profile) أو [الذاكرة](/docs/agents/learning-agent-memory)، أو تكليف مختص مباشرة. اختيار الأسلوب والموعد موجود تحت «تحديد الأسلوب أو الموعد (اختياري)»؛ ترك الأسلوب تلقائياً يكفي.

## النشر والجدولة

يتولى الفريق [النشر الفعلي](/docs/agents/learning-agent-published) وفق التفويض. يستطيع أيضاً إصلاح مسودة سابقة من الدرس ونشرها دون نسخها. عندما يرفض فحص الجودة محتوى قابلاً للإصلاح، يتلقى المساعد السبب ليعالجه. إذا نقص المصدر أو تغيرت المسودة أثناء العمل، يذكر سبب التعثر.

يمكن [تأجيل المهمة](/docs/agents/learning-agent-schedule) أو [إلغاؤها](/docs/agents/learning-agent-cancel) أو [استئنافها بعد الانقطاع](/docs/agents/learning-agent-resume). تظهر النتيجة الأخيرة، ويمكن توسيع «الطلب وخطوات التنفيذ» إذا احتجت التفاصيل. التشغيل المجدول يتطلب بقاء تطبيق المعلم مفتوحاً.

## حدود تساعدك على تفسير النتائج

- يعتمد الفريق على النص المحفوظ في الدرس؛ إرفاق ملف أو صورة لا يعني قراءة محتواهما.
- المحلل يفصل الدرجات الجزئية عن المحاولات غير المصححة، ويذكر حدود العدد القليل. لا يشخّص قدرات الطالب.
- الجدولة تحتاج إلى تشغيل التطبيق. التنفيذ محدود بوقت وعدد خطوات، وليس عملاً مفتوحاً بلا نهاية.
- تصحيح التفسيرات الحرة ما زال يدوياً. طلب التحليل أو المراجعة ينفذ مرة واحدة؛ لا يشغّل مراقبة تلقائية للإجابات اللاحقة.
- فحص الجودة قد يتعثر أو يبالغ في التحفظ. يذكر الفريق ما لم يستطع حله؛ لا تعني حالة «مكتملة» أن النشر نجح دائماً.
