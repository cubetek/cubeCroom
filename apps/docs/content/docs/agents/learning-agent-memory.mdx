## ماذا تفعل هنا

- اكتب تفضيلاً أو معلومة تعليمية في «ذكرى جديدة»، ثم «أضف إلى الذاكرة».
- لتصحيح ملاحظة، عدّل نصها ثم اضغط «حفظ التعديل».
- احذف الملاحظة غير المناسبة بزر «حذف». راجع أيضاً الملاحظات التي يحفظها المساعد من الدرس.

<Callout title="انتبه">
الذاكرة خاصة بالمساعد والفصل. استخدم معلومات تعليمية واضحة، ولا تعامل ملاحظة المساعد على أنها حقيقة عن قدرات طالب.
</Callout>
