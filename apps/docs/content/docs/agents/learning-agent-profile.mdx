## ماذا تفعل هنا

- عدّل «رسالته وطريقة تعامله» لتحديد نبرته وأولوياته.
- اكتب تعليمات قصيرة قابلة للتطبيق: المرحلة، طول الأسئلة، نوع الأمثلة وما ينبغي التحقق منه.
- اضغط «حفظ الشخصية والتفويض» قبل اختيار مختص آخر أو بدء مهمة.

<Callout title="انتبه">
الشخصية إعداد للمساعد، والذاكرة معلومات محفوظة يرجع إليها. افحص الفصل والدرس المختارين عند كل مهمة.
</Callout>
