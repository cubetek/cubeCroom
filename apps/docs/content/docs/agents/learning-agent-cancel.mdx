## ماذا تفعل هنا

- حدد المهمة المطلوبة في السجل.
- اضغط «إلغاء» عندما تكون في قائمة العمل أو تعمل الآن.
- تحقق من حالة «ملغاة». الأعمال التي حُفظت قبل الإلغاء تبقى متاحة.

<Callout title="انتبه">
لإعادة مهمة ملغاة أنشئ طلباً جديداً. زر «استئناف» مخصص للمهام المتعثرة أو المنقطعة عندما يظهر.
</Callout>
