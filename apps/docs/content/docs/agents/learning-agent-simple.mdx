## ماذا تفعل هنا

- افتح «فريق المساعدين». يحتفظ البرنامج بالفصل والدرس الأخيرين؛ غيّرهما عند الحاجة.
- اختر «جهّز تجربة للدرس» أو «لخّص ما يحتاج انتباهي» أو «جهّز مراجعة حسب النتائج». يمكنك أيضاً كتابة طلبك.
- اضغط «ابدأ المهمة». يتولى الفريق قراءة الدرس والذاكرة واختيار المختصين وإعداد العمل وحفظه.

<Callout title="انتبه">
تفويض النشر اختيار محفوظ لهذا الفصل: عند تفعيله ينشر الفريق التجربة بعد فحص الجودة، وعند إيقافه يحفظ مسودة. الشخصية والذاكرة والأسلوب والموعد تخصيصات اختيارية.
</Callout>
