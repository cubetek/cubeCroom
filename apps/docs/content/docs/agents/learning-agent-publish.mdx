## ماذا تفعل هنا

- في الطلب المبسط فعّل «انشر التجارب الجاهزة في هذا الفصل بعد فحص الجودة». يحفظ البرنامج التفويض للمنسق.
- ابدأ طلب التجهيز؛ يتولى الفريق الحفظ والفحص والنشر. يمكنك أيضاً طلب مراجعة مسودة سابقة ونشرها.
- إذا احتاج المحتوى إصلاحاً يستطيع الفريق تعديل المسودة نفسها ثم إعادة الفحص. يظهر السبب عندما يتعذر إتمامها.

<Callout title="انتبه">
يبقى نطاق النشر محصوراً بالفصل والدرس المحددين. يمكن تخصيص تفويض مختص آخر من إعدادات الفريق. سحب التفويض يمنع النشر، ولا يسحب التجارب المنشورة سابقاً.
</Callout>
