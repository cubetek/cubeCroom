## ماذا تفعل هنا

- لخدمة سحابية اختر OpenAI أو Anthropic أو Google أو OpenRouter، ثم اضغط «ربط المفتاح».
- لنموذج محلي شغّل LM Studio أو Ollama أولاً، ثم اضغط «ربط الخادم» وأدخل عنوانه.
- اضغط «اختبار الاتصال»، ثم اختر النموذج واضغط «حفظ واستخدام». تظهر شارة «مستخدم الآن» على المزوّد المختار.
- بعد الربط يمكنك استعمال المساعدة في تحضير الدروس والأسئلة. راجع [إعداد المزوّدين السحابيين](/docs/ai/cloud-providers) أو [المزوّدين المحليين](/docs/ai/local-providers).
- مساعدة الطلاب لها مفاتيح مستقلة: [فعّلها للفصول والأنشطة التي تختارها](/docs/ai/student-ai).

<Callout title="انتبه">
الربط اختياري للوظائف الصفّية الأساسية. عند استخدام الذكاء الاصطناعي تُرسل مادة الطلب إلى المزوّد أو الخادم المختار؛ راجع وجهة المعالجة قبل إدخال معلومات الطلاب.
</Callout>
