## ماذا تفعل هنا

- اضغط «إنشاء نسخة احتياطية الآن»، وانتظر ظهور النسخة بحالة «اكتملت».
- اضغط «فتح مجلد النسخ» للوصول إليها. انسخ مجلد النسخة كاملاً إلى قرص آخر للاحتفاظ بنسخة خارج جهازك.
- للاستعادة، اختر «استعادة» بجانب نسخة مكتملة، واقرأ تاريخها وما سيُفقد قبل تأكيد «استعادة هذه النسخة».
- لتغيير مكان بيانات التطبيق، افتح «الإعدادات» ثم «مكان البيانات» واضغط «نقل البيانات».

<Callout title="انتبه">
الاستعادة ترجع البيانات إلى وقت النسخة، ويُعاد تشغيل التطبيق بعدها. أنهِ الحصة أولاً؛ يحفظ التطبيق نسخة من الوضع الحالي قبل استبداله.
</Callout>
